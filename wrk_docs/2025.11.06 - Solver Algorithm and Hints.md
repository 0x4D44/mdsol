# Solver Algorithm and Hint System - Comprehensive Analysis

## Executive Summary

The mdsol solver (src/solver.rs) uses iterative DFS with transposition tables to prove Klondike solitaire winnability in ~120ms. The K+ compressed representation is the key innovation, eliminating redundant stock/waste states. The hint system (main.rs:3718-3889) is separate and uses rule-based heuristics, not the solver.
