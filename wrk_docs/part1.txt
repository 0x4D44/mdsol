## Overview

The Solitaire project uses a sophisticated asset pipeline to generate card graphics and compile them into the Windows executable as embedded resources. The system is designed with fallback mechanisms, high-quality rendering, and complete automation in mind.

**Key Components:**
- **xtask**: Cargo workspace member for asset generation tools
- **build.rs**: Build script for Win32 resource compilation
- **res/app.rc**: Win32 resource definition file
- **cards.png**: 13x4 sprite sheet (2912x1248 pixels, 1.5MB)
- **Inno Setup**: Installer creation for distribution

**Key Library Purposes:**
- **clap**: Command-line argument parsing with derive macros
- **reqwest**: HTTP client with rustls for TLS (no OpenSSL dependency)
- **zip**: Archive extraction for downloaded card sets
- **usvg**: SVG parsing to intermediate tree representation
- **resvg**: SVG rendering engine
- **tiny-skia**: Low-level 2D graphics (pixmap management)
- **image**: Image encoding/decoding (PNG export)
- **walkdir**: Recursive directory traversal
