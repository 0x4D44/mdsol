## Core Data Structures

### Card Structure (Lines 89-107)

The fundamental unit of the game:

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Card {
    pub suit: Suit,        // Spades, Hearts, Diamonds, Clubs
    pub rank: Rank,        // Ace through King
    pub face_up: bool,     // Visibility state
    pub sprite_index: u8,  // Pre-computed sprite position
}
```

**Key Points:**
- `Card` is `Copy` - enables efficient stack allocation
- `sprite_index` = `suit.row() * 13 + rank.column()`
- Pre-computation eliminates runtime calculation during rendering
- All cards start face-down via `Card::new(suit, rank)`

### Suit Enumeration (Lines 34-64)

```rust
pub enum Suit {
```

**Methods:**

**Color Mapping:**

## Deck Creation and Shuffling

### BCrypt RNG Seeding (Lines 949-968)

Uses Windows BCrypt API for cryptographically secure 64-bit seeds. This ensures truly unpredictable deals with 2^64 possible combinations.

### Fisher-Yates Shuffle (Lines 941-947)

Standard unbiased O(n) shuffle algorithm. Same seed always produces identical shuffle enabling game replay.

### ShuffleRng xorshift64* (Lines 1016-1033)

Fast deterministic PRNG with period 2^64-1. Zero seed protected with fallback 0x4D44_5EED.

**Two-Layer Design:**
- BCrypt: Unpredictable seed generation  
- xorshift64*: Deterministic shuffling
- Result: Fair and replayable games

## Game Initialization

### Deal Pattern (Lines 240-290)

Tableaus receive 1, 2, 3, 4, 5, 6, 7 cards respectively (28 total). Top card in each tableau face-up. Remaining 24 cards go to stock face-down.

**Score Initialization:**
- Standard: 0
- Vegas non-cumulative: -$52
- Vegas cumulative: current_score - $52

## Move Validation Rules

### Foundation Rules (Lines 992-999)

Empty foundation requires Ace. Non-empty requires same suit and rank = top + 1. Build sequence A through K.

### Tableau Rules (Lines 1001-1010)

Empty tableau requires King. Non-empty requires: top face-up, alternating colors, descending rank by 1.

### Stack Validation (Lines 970-990)

Multi-card moves: all face-up, alternating colors throughout, descending ranks by 1.

## Stock and Waste Management

### Stock Click (Lines 291-307)

If stock has cards: draw 1 or 3 to waste. If stock empty: recycle waste to stock. Unlimited recycling allowed.

### Draw Logic (Lines 451-472)

Pop up to N cards from stock (N=1 or 3), flip face-up, push to waste. Increment moves once per draw action.

### Recycle Logic (Lines 474-488)

Pop all waste cards, flip face-down, push to stock. Reverses order. Increment moves once.

## Foundation Rules

### Place on Foundation (Lines 587-598)

Atomic operation. Scoring: Standard +10, Vegas +$5. Increments move counter.

### Waste to Foundation (Lines 325-339)

Pop from waste, attempt place, rollback if fails (atomic).

### Tableau to Foundation (Lines 362-380)

Pop from tableau, place on foundation, auto-reveal new tableau top.

## Tableau Rules

### Extract Stack (Lines 390-407)

Validates stack is valid run. Returns stack or None with automatic rollback if invalid.

### Place Stack (Lines 427-435)

Validates destination accepts stack. Appends if valid, increments moves.

### Card Revealing

**Manual Flip:** Increments moves, Standard +5 points  
**Auto Reveal:** After moves, no move increment, Standard +5 points

## Scoring System

### Standard Scoring

- Waste to Tableau: +5
- Waste/Tableau to Foundation: +10
- Card Flip: +5
- Starts at 0, no penalties

### Vegas Scoring

- Buy-in: -$52 per deal
- Foundation: +$5 per card
- Other moves: $0
- Cumulative mode accumulates debt
- Max possible: +$208 (52 cards * $5 - $52)

## State Transitions

### Invariants

1. Total cards == 52
2. Each card appears once
3. Stock cards face-down
4. Waste top face-up
5. Foundation cards face-up and sequential
6. Tableau top face-up after reveal
7. rng_seed != 0 after deal

### Atomic Operations

All moves succeed completely or rollback completely. No partial states.

### Move Counter

Incremented for: draws, recycles, flips (manual), moves between piles.  
Not incremented for: auto-reveals, validation, queries.
